How the platform's journey works, step by step.

The Full Journey

Login/Register → New or Resume Session → Upload Data → Profile Data → Choose Goal → Choose Workflow → Clean Data → Feature Engineering → Explore Data (EDA) → Train Models → Compare Models → Explain Decisions → Get Recommendations → What-If Simulation → Explainability → Alerts → Final Report → Done (Resume Anytime Later).

Tips

  • Use the sidebar to jump between steps once a project is open.
  • Every page shows a "Console Output" panel with exactly what your backend functions printed.
  • Unfinished projects can be resumed from the Dashboard or Saved Projects page at any time.
  • Charts and reports are saved to disk in the charts/ and reports/ folders, and are downloadable from the app.
